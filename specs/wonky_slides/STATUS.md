# Wonky Slides — implementation status

Wonky Slides was built in the waves of [12-implementation-plan.md](12-implementation-plan.md)
(M9 Slides MVP → M10 motion & content → M11 collaboration, MCP & AI) and is **complete for its
first iteration** (M11 closed with SL-45). Each row describes one work package as built; what is
left — hidden features, the on-hold SL-41, P1/P2 items and missing checks — is in the root
`TODO.md` ("Wonky Slides — later"), per-package leftovers in "Wonky Slides — open items".

**M9 status (SL-23, 2026-10-15): closed — Slides MVP integrated.** Everything not built for M9
is hidden (`wonky_slides/lib/config/slides_features.dart`), and the remaining work packages
(SL-25, SL-27…SL-45) with what is already in place went to `TODO.md` ("Wonky Slides —
later"). What of the M9 exit gate was verified and what wasn't: `specs/14-roadmap.md` §2.1
("M9 exit checklist").

**M10 status (SL-36, 2026-10-15): closed — motion & content integrated.** On since M10: builds
and transitions incl. 3D and Magic Move (`animations`), code blocks with highlight steps and
type-in/morph (`codeBlocks`), linked Sheets charts incl. 3D camera (`charts`), masters/layout
editing and the theme editor (`masters`), PDF builds as pages and PNG export (`printBuilds`,
`imageExports`), outline view, Layers, accessibility checker, Write exports on the shared
tokenizer, and 10 of 10 templates. Still hidden: native charts (P1), motion-path editing, the
M11 features. What of the M10 exit gate was verified and what wasn't: `specs/14-roadmap.md` §2.1
("M10 exit checklist"); leftovers in `TODO.md`.

**M11 status (SL-45, 2026-10-15): closed — Wonky Slides complete for its first iteration.** On
since M11: live collaboration (pointers, follow, follower view of a presentation), comments on
slides and elements, version history with diffs, restore and copies, overwritten-text review,
MCP `slides.*` and `ui.slides.*`, the assistant and AI commands, spelling, presentation
language, special characters and emoji, image adjustment preview, connector route handles. On
hold (user decision): SL-41 phone remote, rehearse and the same-browser fast path
(`remoteAndRehearse` off). Still hidden: native charts and *Import slides…* (P1), *Make a code
walkthrough…*, editor preferences, notification settings, Markdown outline export and snap to
grid (P2). What of the M11 exit gate was verified and what wasn't: `specs/14-roadmap.md` §2.1
("M11 exit checklist").

**M13 status (RevLog, R7): built — Wonky Slides syncs through RevLog** ([17](../17-revlog-sync.md),
milestone M13 in `specs/14-roadmap.md`). Decks are RevLog files: the 12 deck tables are server
tables, every change is an op of the file's log, the client keeps a cache and an outbox
(`LoggedDeckSession`, `SlidesRevLog`), server writers submit server changes
(`SlidesServerWrites`), hooks replace the change-log consumer and headless decks come from
`HeadlessFileCache` (row R7 below; 02 §3, §9–§12, 09 §4–§6, 11 §2.1). The rows below record
the work packages as built on the offline-sync engine: their sync parts — SL-2, SL-5, SL-8 and
SL-9, and mentions of the replica, reserved spaces, `DeckChangeLog` or `ServerSlidesWriter` in
other rows (e.g. SL-22, SL-39, SL-40) — are superseded by R7. Follow-ups: *Save my changes as a copy* when ops are rejected (17 As
built 10), an overwritten-text review fed directly by the ops' outcomes (17 As built 11, 09
§6.3), the *Download unsynced changes* recovery of a cache that can't be opened (17 As built 15)
and character-level text merging (02 §4.5 option C, unblocked by RevLog).
